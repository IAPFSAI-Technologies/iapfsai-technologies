# IAPFSAI Technologies

A responsive one-page website for IAPFSAI Technologies, a technology partner building scalable SaaS platforms, intelligent automation, and custom AI solutions.

## What is included

- Hero section with company positioning and business metrics
- Product showcase for ResumeCareerAI and ERP AI Solution
- Services and milestone-based delivery process
- Industries served, client testimonial, FAQ, and contact CTA
- Responsive navigation and mobile layout
- Interactive FAQ accordion and mobile menu

## Run locally

This is a dependency-free static page. Open `index.html` directly in a browser, or serve the repository with any static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
